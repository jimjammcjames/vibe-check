# Add a Notification Service

You are working on a TypeScript codebase. Your task is to add a notification service.

## Requirements

1. Create a `NotificationService` class in `src/notifications/`
2. It should support multiple channels (email, SMS, push)
3. Use a provider pattern - each channel has its own provider class
4. Include proper TypeScript types

## Important

- You should follow the project's standards for tracking decisions and features.
